# HeroX App Store 🚀

Live Demo: https://heroxapp.netlify.app/

## 📌 Project Overview

HeroX App Store is a React Router-based practice project where users can explore a list of applications, view detailed information about each app, search apps dynamically, and install apps (stored in localStorage).

This project was built to improve skills in:

- React Router (loaders, dynamic routes, error handling)
- State management in React
- LocalStorage usage
- UI development with Tailwind CSS / DaisyUI
