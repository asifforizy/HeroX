# HeroX App Store 🚀

Live Demo: https://heroxapp.netlify.app/

## 📌 Project Overview

HeroX App Store is a React Router-based practice project where users can explore a list of applications, view detailed information about each app, search apps dynamically, and install apps (stored in localStorage).

This project was built to improve skills in:

- React Router (loaders, dynamic routes, error handling)
- State management in React
- LocalStorage usage
- UI development with Tailwind CSS / DaisyUI

---

## ✨ Features

- 📱 **Browse Apps**: Explore a comprehensive list of applications
- 🔍 **Dynamic Search**: Search and filter apps in real-time
- 📖 **App Details**: View detailed information about each application
- 💾 **Install Apps**: Install and manage apps with localStorage persistence
- 🎨 **Modern UI**: Built with Tailwind CSS and DaisyUI components
- 🛣️ **Client-Side Routing**: Seamless navigation with React Router
- ⚡ **Error Handling**: Robust error pages and fallback handling

---

## 🛠️ Tech Stack

- **Frontend Framework**: React 18+
- **Routing**: React Router v6+
- **Styling**: Tailwind CSS
- **UI Components**: DaisyUI
- **State Management**: React Hooks (useState, useContext)
- **Storage**: Browser LocalStorage API
- **Language**: JavaScript (ES6+)
